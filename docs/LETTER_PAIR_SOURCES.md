# Mnemonic data

The application uses `web/src/workspace/data/mnemonicSuggestions.ts` through `utils/suggestions.ts`. Suggested words are optional and are never saved without user action. User-created words remain separate private workspace data.

The source contains curated entries, a word bank and letter images used to generate fallbacks. Existing project notes claim original curation informed by public blindsolving resources, but no author declaration, source-level license or complete provenance record establishes redistribution rights. Common words and names do not establish ownership of the selection or arrangement.

**Publication is blocked until the repository owner confirms authorship and redistribution rights for this corpus, or replaces it with a documented compatible dataset.** The root MIT license does not grant rights in this unresolved corpus.
