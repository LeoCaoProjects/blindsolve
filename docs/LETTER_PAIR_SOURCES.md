# Mnemonic data provenance

`web/src/workspace/data/mnemonicSuggestions.ts` contains the suggested words,
word bank and letter images used by `web/src/workspace/utils/suggestions.ts`.
User-created words are separate workspace data.

No author declaration, source license or complete provenance record establishes
redistribution permission for this corpus. It is excluded from the root MIT
license; that license must not be treated as permission to redistribute it.
